## UI Style Guide

### Color Palette
```
Primary: #6B46C1 (Void Purple)
Secondary: #4299E1 (Energy Blue)
Accent: #ED8936 (Energy Orange)
Success: #48BB78 (Heal Green)
Warning: #ECC94B (Mana Yellow)
Danger: #F56565 (Damage Red)
Background: #1A202C (Dark Void)
Surface: #2D3748 (Crystal Gray)
Text: #F7FAFC (Light Ethereal)
```

### Typography
- **Headers:** Cinzel (fantasy style)
- **Body:** Inter (clean readability)
- **Numbers:** Roboto Mono (monospace for stats)

### Design Language
- **Shapes:** Organic curves with sharp corners
- **Textures:** Subtle crystal patterns, energy effects
- **Animations:** Smooth transitions with particle effects
- **Feedback:** Visual pulse on interaction

## UI Animations & VFX

### Button Interactions
- **Hover:** Glow pulse (0.2s)
- **Click:** Scale down + sound
- **Active:** Sustained glow
- **Disabled:** Grayed out + no interaction

### Notification Popups
- **Entrance:** Slide from edge (0.3s)
- **停留:** Brief pause
- **Exit:** Fade out (0.2s)

### Level Up Animation
- Character glow effect
- Number counter animation
- Sound cue
- Particle burst

### Damage Numbers
- **Normal:** White, fade up
- **Critical:** Orange, larger, faster
- **Heal:** Green, sparkle effect
- **Miss:** Gray, X mark
